# canditature microservice

Spring Boot 4 / Java 17 service for job applications (Candidature).

## Quick access (run CanditatureApplication first)

| Endpoint | Method | Link |
|---|---|---|
| Hello test | GET | [👉 /mic3/candidature/hello](http://localhost:8083/mic3/candidature/hello) |

Expected response: `Hello Im microservice 3!`

## Run
1. Open `src/main/java/esprit/canditature/CanditatureApplication.java`.
2. Click the green ▶ next to `main`.
3. Wait for `Started CanditatureApplication` in the console.
4. Click the link above.

## Config
- Port: `8083` (set in `src/main/resources/application.properties`)
